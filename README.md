# ₿ Crypto Market Intelligence & Anomaly Detection Dashboard

A real-time cryptocurrency analytics dashboard built using Python and Streamlit. The dashboard retrieves live cryptocurrency market data from the CoinGecko API and provides interactive price analysis and anomaly detection.

## 🚀 Features

- 📊 Live cryptocurrency price monitoring
- 💰 Current price, market cap and 24H volume
- 📈 Interactive historical price charts
- 🔄 Automatic dashboard refresh every 60 seconds
- 🪙 Bitcoin, Ethereum and Solana support
- 🚨 Statistical anomaly detection using Z-score
- 📋 Recent market data table
- 🔍 Interactive Plotly charts
- 📅 Multiple time ranges: 1H, 24H, 7D, 30D and 1Y
